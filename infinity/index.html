The Infinity suite

Five Windows applications that need nothing but Windows. No runtime, no DLL to install beside them, no installer required to get them running — each product is a single executable of a few hundred kilobytes.

How it fits together

Two faces, one executable

Every product has a command line (<p>_cli.exe) and a window (<p>_gui.exe). The window is Electron rendering a page served by the same executable, so the executable is still the whole program. The terminal interface was removed: it duplicated the window without being better at anything.

One catalogue

Products, plugins and resource packs all come from one index — a GitHub repository where each release is a catalogue page. Infinity Installer Manager is the single entry point that reads it.

Nothing runs unverified

A package is only installed if the SHA-256 of the bytes on disk matches the digest GitHub reports for that asset. A build with no digest is refused rather than trusted.
