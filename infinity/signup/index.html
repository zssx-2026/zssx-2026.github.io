Sign up

There is nothing to register here, and that is deliberate. The suite has no accounts, no server and no database of users — it stores everything in your own GitHub account. Signing up means having a GitHub account and a token for it.

1. A GitHub account

If you already have one, skip this. If not, create it at github.com/signup. The free tier is enough; the suite stores its data in releases, which are free on public repositories and available on private ones too.

Create a GitHub account

2. A token

A token is how a program acts as you without your password. Create one at github.com/settings/tokens.

A classic token needs the repo scope. A fine-grained token needs read and write access to Contents on the repositories you want to use. Give it an expiry you are comfortable with — the suite reads the token from an environment variable, so replacing it later is one setting, not a reinstall.

Create a token

3. Hand it over

For this website, paste it on the sign in page. For a desktop program, set the environment variable it reads — the documentation names it — or use the link a product page.
