Each product installs on its own. If you want all of them, install Infinity Installer Manager instead — it reads the same catalogue and installs the products, plugins and resource packs from one place.

Products

Requirements

Windows 10 or later. That is the whole list. The executables import only DLLs that ship with Windows — kernel32, user32, gdi32, winhttp and the UCRT forwarders — so there is no runtime to install, no framework to download and nothing to keep updated beside the program itself.

You will need a GitHub account and a personal access token: the suite stores its data in GitHub releases. See the documentation for how to create one.
