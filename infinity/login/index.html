Sign in

This site has no accounts of its own. Signing in means handing it a GitHub personal access token, which it keeps in this browser and uses to read the repositories the suite stores its data in.

Kept in this browser's local storage. It is sent only to api.github.com, never to this site — there is no server here to send it to.

Create a token

What the token needs

A classic token with the repo scope, or a fine-grained token with read and write access to Contents for the repositories you want the suite to use. Read access alone is enough to browse; uploading needs write.

The token is a password. Treat it like one — the link a product page explains how to hand it to a desktop program without pasting it into a chat window.
